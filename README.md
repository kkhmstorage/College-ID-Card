# College ID Card Designer

> College Identity Card Design & Management System  
> KKHM Islamic & Arts College | AL-GAITH Islamic & Arts College for Girls

## ✨ Features

- 🏛️ **Institution Switching** — Switch between KKHM & AL-GAITH with one click
- 📇 **3 Card Types** — Student ID / Staff ID / Visitor Pass
- 📸 **Photo Drag & Zoom** — Drag uploaded photo to perfect position + Zoom control
- 🔒 **Visitor Restrictions** — Only pre-registered blood-relatives (via office)
- 📱 **QR Code** — Auto-generated QR code on each card
- 🖼️ **Logo Upload** — Upload institution logo for the card
- 🌐 **Website & Contact** — Website, phone, address on card
- 🔄 **Front/Back Side** — Preview & download both sides
- 🎨 **Theme Colors** — 8 presets + custom color picker
- 📥 **PNG Download** — Download Front, Back, or Both sides

## 🚀 How to Use

1. Open `index.html` in your browser
2. Select institution (KKHM / AL-GAITH)
3. Choose card type (Student / Staff / Visitor)
4. Fill in the details
5. Upload photo & logo
6. Drag photo to adjust position
7. Download the card as PNG
